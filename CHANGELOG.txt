ARCHITECTURE NOTES
------------------------------------------------------------------------

- Frontend-only: zero backend calls, all data hardcoded/simulated
- Dark mode forced permanently via document.documentElement.classList.add("dark")
- Lenis smooth scroll initializes only after gateway is dismissed
- Canvas elements: always absolute inset-0 inside relative parent with height
- Google Fonts import must be first line in index.css (before Tailwind imports)
- No emojis in UI (preference enforced throughout)
- All animations intentional and premium — no decorative noise
